# Banking Widget

Виджет для обработки, фильтрации и анализа банковских транзакций клиента.

## Описание функциональности

### 1. Маскирование номеров (`src/masks.py`, `src/widget.py`)
- Маскирование номеров банковских карт: `XXXX XX** **** XXXX`.
- Маскирование номеров банковских счетов: `**XXXX`.
- Форматирование дат транзакций в читаемый вид (`ДД.ММ.ГГГГ`).

### 2. Фильтрация и сортировка (`src/processing.py`)
- Фильтрация операций по статусу (`EXECUTED`, `CANCELED`, `PENDING`).
- Сортировка списка операций по дате (по возрастанию или по убыванию).

### 3. Генераторы (`src/generators.py`)
- Итерация по транзакциям с фильтрацией по заданной валюте.
- Генератор описаний банковских операций.
- Генератор номеров банковских карт в заданном диапазоне.

### 4. Декораторы (`src/decorators.py`)
- Декоратор `@log`: автоматическое логирование начала/успешного завершения работы функции и возникающих ошибок в консоль или в указанный файл.

### 5. Конвертация валют и работа с внешним API (`src/utils.py`, `src/external_api.py`)
- Чтение транзакций из JSON-файлов (`get_transactions_data`).
- Конвертация суммы валютных операций (USD, EUR) в рубли через Exchange Rates Data API (`convert_to_rubles`).

### 6. Логирование (`src/logger.py`)
- Настройка файлового логирования для модулей `masks` и `utils`.
- Логи сохраняются в папку `logs/` (`masks.log`, `utils.log`) с перезаписью при каждом старте приложения (`mode='w'`).
- Запись временной метки, имени модуля, уровня важности и описания события/ошибки.

### 7. Работа с CSV- и Excel-файлами (`src/csv_excel.py`)
- `read_transactions_from_csv(file_path)`: считывание операций из файлов формата CSV с помощью библиотеки `pandas`.
- `read_transactions_from_excel(file_path)`: считывание операций из электронных таблиц Excel (`.xlsx`) с помощью `pandas` и `openpyxl`.

### 8. Поиск по описанию и статистика категорий (`src/services.py`)
- `process_bank_search(data, search)`: регистронезависимый поиск транзакций по подстроке в поле `description` с использованием модуля регулярных выражений `re`.
- `process_bank_operations(data, categories)`: подсчет количества операций по заданным категориям на основе поля `description` с помощью `collections.Counter`.

### 9. Интерактивный консольный интерфейс (`main.py`)
- Главная точка входа в программу.
- Интерактивный диалог с пользователем:
  - выбор источника данных (JSON, CSV, XLSX);
  - фильтрация по статусу операции (`EXECUTED`, `CANCELED`, `PENDING`);
  - сортировка по дате (по возрастанию / убыванию);
  - фильтрация только рублевых транзакций;
  - поиск по ключевому слову в описании;
  - форматированный вывод итогового списка транзакций с маскированием счетов и карт.
