# Banking Widget

Виджет для обработки и анализа банковских транзакций клиента.

## Описание функциональности

### 1. Маскирование номеров (`src/masks.py`, `src/widget.py`)
- Маскирование номеров банковских карт: `XXXX XX** **** XXXX`.
- Маскирование номеров банковских счетов: `**XXXX`.
- Форматирование дат транзакций (`ДД.ММ.ГГГГ`).

### 2. Фильтрация и сортировка (`src/processing.py`)
- Фильтрация операций по статусу (`EXECUTED`, `CANCELED`).
- Сортировка операций по дате.

### 3. Генераторы (`src/generators.py`)
- Итерация по транзакциям с фильтрацией по валюте.
- Генератор описаний операций.
- Генератор номеров банковских карт в заданном диапазоне.

### 4. Декораторы (`src/decorators.py`)
- Декоратор `@log`: логирование работы функций и ошибок в консоль или в файл.

### 5. Конвертация валют и чтение JSON (`src/utils.py`, `src/external_api.py`)
- Чтение транзакций из формата JSON (`get_transactions_data`).
- Конвертация суммы валютных операций (USD, EUR) в рубли через Exchange Rates API (`convert_to_rubles`).

### 6. Логирование (`src/logger.py`)
- Настройка сквозного логирования для модулей `masks` и `utils`.
- Логи сохраняются в папку `logs/` (`masks.log`, `utils.log`) с перезаписью при старте.

### 7. Работа с CSV и Excel файлами (`src/csv_excel.py`)
- `read_transactions_from_csv(file_path)`: считывание транзакций из файлов формата CSV.
- `read_transactions_from_excel(file_path)`: считывание транзакций из таблиц Excel (`.xlsx`).
